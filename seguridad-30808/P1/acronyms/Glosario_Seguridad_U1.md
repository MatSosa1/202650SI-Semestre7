# Glosario de Acrónimos: Ingeniería de Seguridad (Unidad 1)

Este documento contiene un resumen detallado de los acrónimos, significados y conceptos clave para el estudio de la seguridad informática.

---

## 1. Fundamentos y Pilares de la Seguridad

| Acrónimo | Significado Literal | Concepto / ¿Qué es? |
| :--- | :--- | :--- |
| **CID (o CIA)** | Confidencialidad, Integridad y Disponibilidad | Los tres pilares básicos de la seguridad de la información. |
| **NR** | No Repudio | Garantiza que el emisor de un mensaje o acción no pueda negar su autoría. |
| **ID** | Identificación | El acto de declarar quién eres ante un sistema (ej. nombre de usuario). |
| **AU** | Autenticación | El proceso de demostrar que eres quien dices ser (ej. mediante contraseña). |
| **TZ** | Trazabilidad | Capacidad de seguir el rastro histórico de un evento o acceso mediante logs. |
| **COIP** | Código Orgánico Integral Penal | Marco legal en Ecuador que tipifica y sanciona los delitos informáticos. |

---

## 2. Centros de Operaciones y Equipos de Respuesta

| Acrónimo | Significado Literal | Concepto / ¿Qué es? |
| :--- | :--- | :--- |
| **SOC** | Security Operations Center | Centro donde un equipo humano supervisa y defiende la infraestructura 24/7. |
| **CSIRT** | Computer Security Incident Response Team | Equipo técnico encargado de recibir y responder a reportes de incidentes. |
| **CERT** | Computer Emergency Response Team | Equipo de respuesta ante emergencias (término similar a CSIRT). |

---

## 3. Tecnologías de Detección y Gestión de Seguridad

| Acrónimo | Significado Literal | Concepto / ¿Qué es? |
| :--- | :--- | :--- |
| **SIEM** | Security Information and Event Management | Sistema que centraliza logs, los correlaciona y genera alarmas en tiempo real. |
| **EDR** | Endpoint Detection and Response | Herramienta que monitorea dispositivos finales contra amenazas avanzadas. |
| **XDR** | Extended Detection and Response | Evolución del EDR que integra datos de red, endpoints y nube. |
| **SOAR** | Security Orchestration, Automation, and Response | Plataforma que automatiza las tareas de respuesta ante incidentes. |
| **UTM** | Unified Threat Management | Dispositivo de red que combina múltiples funciones (firewall, antivirus, VPN). |
| **NGFW** | Next-Generation Firewall | Firewall avanzado que analiza el tráfico a nivel de aplicación (Capa 7). |

---

## 4. Metodologías, Amenazas y Vulnerabilidades

| Acrónimo | Significado Literal | Concepto / ¿Qué es? |
| :--- | :--- | :--- |
| **OSINT** | Open Source Intelligence | Inteligencia obtenida legalmente de fuentes públicas o abiertas. |
| **OWASP** | Open Web Application Security Project | Comunidad que define estándares y riesgos para aplicaciones web. |
| **MAGERIT** | Metodología de Gestión de Riesgos de TI | Estándar para analizar y gestionar los riesgos de los activos. |
| **CVSS** | Common Vulnerability Scoring System | Sistema de puntuación (0 a 10) para medir severidad de vulnerabilidades. |
| **STRIDE** | Spoofing, Tampering, Repudiation, Info Disclosure, DoS, Elevation of Privilege | Modelo para clasificar y modelar amenazas de seguridad. |
| **ZAP** | Zed Attack Proxy | Herramienta de OWASP para encontrar vulnerabilidades web. |

---

## 5. Sistemas de Información (Niveles Organizacionales)

| Acrónimo | Significado Literal | Concepto / ¿Qué es? |
| :--- | :--- | :--- |
| **MIS** | Management Information Systems | Sistemas para el nivel técnico/gestión de información operativa. |
| **DSS** | Decision Support Systems | Sistemas de apoyo a la toma de decisiones para el nivel táctico. |
| **EIS** | Executive Information Systems | Sistemas estratégicos diseñados para la alta gerencia. |
| **ERP** | Enterprise Resource Planning | Software que integra todos los procesos de negocio de una empresa. |
| **CRM** | Customer Relationship Management | Sistema para gestionar la relación y los datos de los clientes. |
