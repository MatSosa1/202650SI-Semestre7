## Código César

$$ C(x) = (x + n) mod26 $$
$$ D(x) = (x - n) mod26 $$

Donde:

C
: Cifrado

D
: Descifrado

x
: Mensaje o la posición de la letra en el abecedario o alfabeto

n
: Desplazamiento

26
: Es el número de letras del alfabeto latino

### Ejemplo

Dado el mensaje ***Security*** cifre con el código césar y un desplazamiento de 5.
