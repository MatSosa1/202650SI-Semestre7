# Factores y Criterios de Calidad del Software

## Modelos Clásicos: El Modelo de McCall

Factores de calidad organizados en tres perspectivas del producto.

### Operación del Producto

Cómo funciona el software en uso

+ Correctitud
+ Eficiencia
+ Integridad
+ Fiabilidad
+ Usabilidad

### Revisión del Producto

Capacidad de prueba y mantenimiento

+ Mantenibilidad
+ Flexibilidad
+ Testeabilidad

### Transición del Producto

Adaptación a nuevos entornos

+ Portabilidad
+ Reusabilidad
+ Interoperabilidad
