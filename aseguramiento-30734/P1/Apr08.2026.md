# Calidad del Software

## Fundamentos

### Concepto

El grado en que un sistema, componente o proceso cumple con los requisitos especificados y las necesidades del usuario.

### Atributos de Calidad del Software (ISO/EIC 25010)

Grado en que un sistema cumple con los requisitos funcionales, de rendimiento, seguridad y experiencia de usuario a lo largo de todo su ciclo de vida.

Adecuación Funcional
: Realiza las funciones necesarias con exactitud.

Eficiencia de Desempeño
: Procesa rápido usando los recursos óptimos.

Usabilidad
: Fácil de aprender, operar y disfrutar.

Fiabilidad
: Mantiene rendimiento bajo condiciones específicas.

Seguridad
: Protege datos contra accesos no autorizados.

Mantenibilidad
: Se modifica y adapta con facilidad.

### Estándares y Modelos de Referencia

ISO 9001 - Gestión de Calidad
: Requisitos para sistemas de gestión de calidad organizacional

ISO/IEC 25000 - _SQuaRE_ (Calidad del Producto)
: Requisitos y evolución de calidad del software. (Incluye ISO/IEC 25010).

ISO/IEC/IEEE 12207 - Ciclo de vida del Software
: Procesos y buenas prácticas desde concepción.

ISTQB* - Pruebas de Software
: Marca internacional de buenas prácticas y certificación del _testing_.

IEEE 829 - Documentación de Pruebas
: Estándar para planes, casos, registros y reportes de pruebas.
